# Archive

Historical engineering records from TribesPad's bring-up: day-by-day status
checkpoints, the original execution plan, build history, an early project review,
raw progress data and rejected experiments.

These files are kept for traceability. Their "next step", "blocked" and
live-process statements are historical and are superseded by the
[handoff](../HANDOFF.md) and the [README](../../README.md).
